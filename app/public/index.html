      Security & privacy notes
      
    
        
  • MVP traffic is plain HTTP on your trusted LAN — it is not
            confidential against someone already on that LAN. Never
            port-forward or expose the device to the internet.
    • 
        
  • You own all captured data: no cloud, no telemetry, no analytics.
            The device URL and pairing token live only in this browser's
            local storage. Forget device clears them.
    • 
        
  • The device has no internet-hosted assets and makes no outbound
            cloud connections.
